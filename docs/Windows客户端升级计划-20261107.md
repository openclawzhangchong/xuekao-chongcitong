# Windows 客户端升级计划（2026-11-07 定稿）

> 教师需求原话：Windows 客户端直接下载就能用；题库等最好内置；不要显示版本号；
> 本地客户端必须有前进/后退（网页 SPA 没法前进后退）；logo 用一个「课」字、右下角标注 zc；配色自定。
> 背景音乐 mp3 放 music/ 文件夹永久生效——客户端里同样适用（本地服务端点已就绪）。

## 一、形态决策（先想清楚再动手）

### 推荐：便携客户端 = 本地服务 + Edge 应用窗口 + 应用内导航（零编译、解压即用）

```
学考冲刺通课堂版/                ← 整个文件夹 zip 分发，解压即用
├─ 启动课堂版.bat               ← 一键：起本地服务 + 打开应用窗口
├─ 停止课堂版服务.bat            ← 结束后台服务（可选，关机也无碍）
├─ 说明（先看我）.txt            ← 三行用法 + music/ 与数据说明
├─ site/index.html + data.js    ← 前端 + 内置题库（3982 题，与仓库同构建）
├─ music/                       ← 教师自备 mp3/wav → 背景音乐永久生效（端点已就绪）
└─ data/                        ← 本地数据库：classroom.json + 学生档案（拷走=备份）
```

- **运行原理**：`启动课堂版.bat` 后台启动班级版服务（Python 标准库，端口 8953，
  已具备本地数据库 /api/classroom、音乐 /api/music、教师页、学生档案），再用
  `msedge --app=http://127.0.0.1:8953/` 打开**独立无边框窗口**（Edge 系统自带，
  零安装；窗口/任务栏图标自动取页面的 favicon——正好承载「课」字 logo）。
- **为什么不用 Electron / Tauri 打 exe**：安装包 200MB/需 Rust 工具链、要处理签名与
  自动更新，与本仓库「零依赖、单文件双击即用」哲学冲突；且本地服务 + 应用窗口方案
  已满足全部需求。**后续若要真 exe，可作为独立升级**（本计划不阻塞）。
- **与网页端的关系**：同一份前端代码三种形态通用（仓库哲学）——网页端、局域网班级版、
  Windows 便携客户端。客户端 = 网页端 + 本地服务 + 应用窗口 + 图标，无分叉代码。

## 二、Logo 与配色规范

- 主图标 `src/favicon.svg`（构建时同时内嵌为单文件 data-URI favicon）：
  - 画布 64×64 圆角方块（圆角 14），背景 **深紫渐变 #6D28D8 → #4C1D95**（呼应全站主色 var(--pri)）；
  - 中央白色「课」字（粗体，占位 ~60%），字体 Microsoft YaHei 粗体回退 sans-serif；
  - 右下角 **「zc」** 小角标（白色 60% 透明度，字号 ~12，贴近右下圆角内缩 4px）；
  - 同 SVG 提供 16/32/64 缩放显示（矢量天然支持）。
- 客户端配色沿用全站主题（浅色默认/深色可切），不为客户端另起配色——保持一个应用一个视觉。
- 应用窗口标题：`学考冲刺通`（Edge --app 取页面 <title>；**不含任何版本号**）。

## 四、前进/后退设计细节（F2，本轮技术核心）

- 路由表：`#/home`（默认）`#/setup`（刷题）`#/quiz`（答题中）`#/wrong` `#/diag` `#/pk` `#/arena`；
  PK/擂台为「页面级」视图（pkPage/arenaPage 全屏），主站面板为 tab 级。
- 入栈时机：switchTab()/showPanel() 与 PK/擂台进入/退出处调用 `navPush(hash)`；
  `window.onpopstate` → 按目标 hash 路由恢复（不重复入栈）。
- 导航按钮：顶栏最左「← →」，基于 history.state 的 index 判断禁用态；
  点击调用 history.back()/forward()。
- 答题中保护：当前在 #/quiz 或 PK/擂台 running 时，后退先走确认框（复用现有 confirm 逻辑）。
- 兼容性：hash 路由在 file://（单文件模式）、http（班级版/主站）、Edge --app 全部可用；
  浏览器原生后退键从此不再「一退就出站」。

## 五、实施步骤（三个提交）

### 提交一：路由与导航（F2/F3/F9，网页端同步受益）
1. hash 路由：switchTab/showPanel/PK/擂台挂 navPush；popstate 恢复；答题中确认
2. 顶栏「← →」按钮（投屏可见）+ Alt+←/→ 快捷键
3. verTag 改无版本号文案；favicon 换「课+zc」SVG（模板内嵌 data-URI + site/favicon.svg）
4. 单测/E2E：路由往返、答题中后退保护、favicon 存在性断言

### 提交二：客户端打包（F1/F4/F5/F8）
1. `tools/build-client.js`：产出 dist-client/ 文件夹 + zip（bat×2 + site + music/（含说明占位）+ favicon + 说明txt）
2. bat 两个（UTF-8/GB 兼容写法）：启动（后台服务 + msedge --app）、停止（按端口 taskkill）
3. 「导出全部数据」入口（F7）
4. E2E：bat 冒烟（起服务→8953 通→页面 200→停止脚本生效）；zip 内容清单断言

### 提交三：收尾
1. 说明（先看我）.txt 定稿；HANDOFF/changelog/交接更新；biji-notes 记录
2. 全站回归（八套单测 + 双闸门 + 三套 E2E + 构建五处同步 + dist-client）
3. 双站部署 + 线上验证（路由/favicon 线上生效）

## 七、风险与边界

| 风险 | 处置 |
|---|---|
| 教师机无 Edge（Win10 早版本） | bat 检测 msedge 不在则回退 `start http://127.0.0.1:8953/` 用默认浏览器打开 |
| 窗口关闭后服务残留 | 提供「停止课堂版服务.bat」；说明里写清「服务常驻是特性，关机即全停」 |
| hash 路由与 file:// 兼容 | 用 hash（非 pushState 路径），file:// 实测；E2E 覆盖 |
| 答题中后退丢会话 | F9 确认框 + 会话状态在内存保留（返回 #/quiz 恢复原题） |
| zip 混入学生数据 | 打包脚本白名单目录；data/ 只带空骨架；打包前断言 |
| Edge app 模式图标不生效 | favicon SVG 是 Edge 官方支持的途径；不生效则补 .ico（后续） |

## 八、明确不做（本轮外）

- Electron/Tauri 真 exe 与安装器、自动更新、代码签名（后续独立升级可做）
- 多窗口/多实例、客户端内嵌教师页（教师页继续走浏览器本机访问）
- macOS/Linux 客户端
