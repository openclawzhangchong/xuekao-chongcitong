# 客户端模式壳层升级计划（2026-11-07 定稿）

> 教师确认两条：①「输入学号」弹窗**保留现状**（不做选名字改造）；
> ②客户端模式下底部 tab **换成上课用的那组**（PK / 擂台等），而不是网页的「首页/刷题/错题/诊断/PK」。
> 教师疑问「客户端是不是要重写」——结论：**客户端本体（托盘+本地服务+窗口）不重写**，
> 只给网页层加一个「客户端模式壳」，一个提交交付；网页端行为 100% 不变。

## 一、客户端底部 tab 组（定稿）

| 顺序 | tab | 落点 | 说明 |
|---|---|---|---|
| 1 | 🏠 首页 | #/home | 预估分/入口卡/荣誉榜（现首页原样） |
| 2 | ⚔️ 双人 PK | #/pk | 现 PK 页 |
| 3 | 🥊 擂台赛 | #/arena | 现擂台页 |
| 4 | 🏆 排行榜 | #/honor | **新独立页**：荣誉墙大字版（今日战况/周擂主/月擂主/PK 获胜总榜 Top10），每次打开实时聚合，投屏展示用 |
| 5 | 📋 备课夹 | #/prep | **新独立页**：备课夹管理卡从首页复用渲染（勾题/清单/清空） |
| 6 | 🎲 课堂互动 | #/class | **新独立页**：名单管理 + 随机点名 + TTS 音色（课堂互动卡复用渲染） |

对比网页 tab（首页/刷题/错题/诊断/PK）：客户端把「上课三件套 + 荣誉激励」PK/擂台/排行榜/
备课夹/点名提到一级导航；刷题/错题/诊断仍从首页入口卡进（教师叫学生上台刷题时走首页）。
教师说明：无内驱力群体靠荣誉感驱动——排行榜单独成页，下课前投屏展示一分钟即可完成「今日表彰」。

## 二、模式判定与生效范围

- 启动器打开窗口时 URL 带 `?client=1`（launcher.cs 一行改动）；
  页面读取后写入 `localStorage.xkc.client='1'`，刷新/后退保持。
- 生效条件：`body.client` 类 + 底部 tab 栏渲染客户端组；**网页端（无标记）行为零变化**。
- 兜底：客户端 exe 启动参数带标记，若教师用浏览器直开 127.0.0.1:8953（无标记）→ 网页模式。

## 三、排行榜页（#/honor，新增设计）

**数据源**：零新增采集——PK 战绩（pk.matches）与擂台时间线（pk.arena.v1.results）
都在课堂数据本地库，页每次打开实时聚合（「每天刷新」天然成立；无数据日自动显示历史）。

**页面区块**（投屏大字版式，从上到下）：
1. **今日战况**：今天打了 N 场 PK · 获胜者名单（没有就显示「今天还没开打，上次的战况如下」）
2. **🥊 周擂主**：擂台赛按自然周重放，本周擂主置顶加大
3. **🥊 月擂主**：擂台赛按自然月重放（同构周逻辑），本月擂主
4. **⚔️ 本周 PK 获胜榜**：本周胜场排序 Top5
5. **👑 班级擂王（截至当前获胜最多）**：PK 获胜总榜第一名——大字展示，本页的「主角」奖励位
6. **⚔️ PK 获胜总榜 Top10**：完整名单（现首页荣誉榜的 Top10 部分移入此页）

**engine 扩展**：aggregateHonor(matches, arenaLog) 增加返回字段——
`monthly`（月擂主，按自然月重放，跨月边界单测）、`weekWins`（本周 PK 胜场排序）、
`today`（今日场次与胜者）；周擂主/总榜逻辑不变。

**首页荣誉卡瘦身**：Top10 表格移入排行榜页后，首页荣誉卡改为「班级擂王 + 本周擂主 + 今日战况」
三行摘要（客户端「查看完整榜单」→ tab 跳排行榜页；网页端跳原卡展开）。

## 四、对战中隐藏规则（沿用既定决策）

PK/擂台**对战进行中**（running）→ 底部 tab 栏隐藏（投屏一屏高度让给题目）；
退出对战/结算后 tab 栏回归。顶栏 ←→ 导航按钮在对战中始终可用。

## 五、技术设计

1. **两个新面板**（不挪动首页卡片，双渲染复用）：
   - `#prep`（备课夹页）+ `#class`（课堂互动页）：markup 各放一份同构容器（id 加 `2` 后缀），
     renderPrepMgr / renderClassroom 改为「渲染到存在的所有容器」（循环两份 id）；
     事件绑定同样双绑。首页卡片保留（网页端用户照旧）。
2. **客户端 tab 栏**：复用现有 .tabs 底栏容器，`body.client` 时由 JS 渲染客户端五项
   （.tab[data-t] 同构，data-t 取 home/pk/arena/prep/class）；非 client 模式渲染原五项。
3. **路由扩展**：TABS 加入 prep/class（客户端模式才生效）；navPush/routeTo/hash 路由直接支持。
4. **launcher.cs**：`--app=http://127.0.0.1:8953/?client=1`（一行）。
5. **学号弹窗**：保留现状——客户端模式下照常弹（与本地数据库归属逻辑一致，不重做）。
