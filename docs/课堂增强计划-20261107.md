# 课堂增强计划（2026-11-07 定稿）

> 背景约束（教师确认）：上课禁带手机 → 所有交互发生在教师机+投影；只有一个班，数据不做分离；
> 学生无内驱力，课堂形态 = 教师讲题 → 叫人上台 PK/擂台；学生课后基本不自主练习（保留开放练习给 2~3 个自觉学生）。
> 用户采纳：备课夹、PK 背景音乐（合成方案）、首页荣誉榜（PK 获胜 Top10 + 周擂主）、
> 本地数据库落盘（战绩不只在浏览器）、KV 数据备份。
> 上轮已认可顺带：舞台键盘快答、换一题按钮（小成本，随本轮交付）。

## 实施顺序（三个提交，依赖关系决定）

### 提交一：本地持久化底座（先做地基，荣誉榜数据才有落点）

1. **班级版服务.py 增加课堂数据端点**
   - `POST /api/classroom`：前端推送战绩快照（PK 比赛记录、擂台战绩、周擂主档案、备课夹）
   - `GET /api/classroom`：启动时拉取合并
   - 存储：`data/classroom.json`（data/ 已 gitignore，学生相关数据不进 git）
   - 写入策略：服务端按时间戳合并追加（matches 只增不改）；每次写入前滚动备份 `.bak`
2. **前端渐进增强**（沿用 /api/hello 探测模式）
   - 有班级版服务：PK/擂台战绩写 localStorage 后异步推送服务器；启动时拉取合并
   - 无服务（单文件双击模式）：纯 localStorage，行为与现在一致
3. **KV 云端备份工具** `tools/kv-backup.js`
   - 拉取 KV 全部 `stu:*` 档案 → `data/backups/kv-YYYYMMDD-HHMM.json`（gitignore 目录）
   - `--restore <文件>` 恢复模式；文档注明「建议每周跑一次」

**验收**：开两次浏览器（清 localStorage 后）战绩仍可从服务器恢复；单文件模式无服务时功能不回归；
worker/班级版单测全绿。

### 提交二：备课夹（本计划核心）

1. **备课夹面板**（课堂互动区新增入口）
   - 按 9 模块/考点浏览题库，复选勾题；显示已选 N 题；可清空/移除单题
   - 顺手入口：答题页/诊断页加「＋加入备课夹」按钮（备课中随手收集）
2. **存储**：localStorage `xkc.prep.v1`（qid 顺序数组）+ 经提交一端点同步到 `data/classroom.json`
3. **PK / 擂台接入**：开赛设置新增「题源：全库随机 / 备课夹」
   - 备课夹模式：**按勾选顺序出题**（教师讲完一题打一题）；两侧同一批题（PK 现有机制）
   - 备课夹题数不足所需题量时提示「备课夹只有 N 题」，可改题量或切回全库
4. **顺带小件**：舞台键盘快答（A/B/C/D/√/× 直接按键选、Enter 提交）；「换一题」按钮（PK/擂台进行中跳过当前题）

**验收**：勾 10 题 → 讲解 → PK 打完 10 题顺序一致；E2E 新增备课夹用例（勾题/题源切换/顺序出题/不足提示）。

### 提交三：首页荣誉榜 + PK 背景音乐

1. **首页荣誉卡**「🏆 荣誉榜」
   - PK 获胜 Top10：按 pk.matches 聚合胜场（姓名/胜场/参赛场次）
   - 周擂主：按周聚合擂台战绩（本周擂主、连胜、守擂场次），历史周留档
   - 首页紧凑卡片 + 点开完整榜；投屏模式大字版
   - 数据来源：提交一的 `data/classroom.json`（跨浏览器/跨周不丢）
2. **PK 背景音乐**（教师定稿：本地文件夹播放器，替代原合成方案）
   - 教师自备 mp3/wav：**放进班级版服务目录的 `music/` 文件夹即永久生效**（/api/music 歌单
     + /music/<文件> 流式播放，服务端已实现）；或在「⚙️ 设置」里临时选本地文件夹
     （webkitdirectory，本次会话有效）
   - 多首自动轮换、一首就单曲播放；默认**关闭**，工具栏「🎵 音乐」开关记忆（pk.bgm）
   - **TTS 自动压低（ducking）**：朗读/表扬播报时降到 20% 音量，播完恢复
   - 已实测：歌单枚举（中文名）、文件流 200 + 正确 Content-Type

**验收**：清 localStorage 后从服务恢复荣誉榜；Top10 与比赛记录一致；BGM 开关记忆、TTS 时不抢话；
E2E 新增荣誉榜用例。

## 明确不做（本轮范围外）

- 多班数据分离（单班确认不需要）
- 全班手机实时竞答（禁手机，作废）
- 学考倒计时/目标分/个人诊断单/防代刷（学生无内驱力场景下低价值，暂缓）
- 学生移动端深度打磨（无设备；教师机投屏模式已大字）

## 铁律不变

qid 迁移管线（改题干必登记）、八套单测+双闸门+三套 E2E、构建五处同步、绝不提交密钥与学生数据
（data/ 已 gitignore）、真实证据交付（evidence/）、双站部署后线上验证。

## 风险与预案

- 浏览器多开冲突：教师单机场景单写者，服务器按 ts 合并兜底
- classrom.json 损坏：写入前滚动 .bak；单文件模式天然不受影响
- KV 备份文件含学生数据：只落 `data/backups/`（gitignored），绝不入 git、绝不入笔记
- 备课夹为空时误选：题源切换处强提示并自动回退全库
